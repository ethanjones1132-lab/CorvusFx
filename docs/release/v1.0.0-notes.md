## Added

### Corvus Instrument (new companion synth)

- New **`IS_SYNTH TRUE`** plugin target with its own identity (`Crvs` / `Cvi1`),
  state format, presets, and editor; the Corvus FX host identity is unchanged.
- **Band-limited wavetable oscillator** with factory waves Sine, Triangle, Saw,
  and Square.
- **16-voice polyphonic engine** with deterministic oldest-released voice
  stealing, note-on/off, sustain pedal, all-notes-off / panic, velocity, and
  pitch bend.
- **Amplitude ADSR** envelope with click-free voice start/release.
- **Global Corvus effects chain** (Distortion → Chorus → Delay → Reverb →
  Master) routed after the voice mix, so patches arrive mix-ready.
- **Flight** performance macro, **FX Amount**, and output level controls.
- **5 signature patches:** Dawn Choir, Raven Glass, Ashen Sky, Northern Signal,
  Cathedral Drift.
- Builds as **VST3** and **Standalone** from the same CMake project.

### Corvus FX features

- **36 factory presets across 6 categories** — CLEAN, WARM, CREATIVE, EXTREME,
  SIGNATURE, DREAM (6 each).
- **MIDI Learn for all 19 knobs** — right-click any knob to map the next CC,
  with per-knob *Forget MIDI Mapping* and global *Clear All MIDI Maps*;
  mappings persist with plugin state.
- **Preset A/B Compare** with `A` / `B` / `SAVE` buttons; snapshots persist
  with the plugin state.
- **Randomize** (`RND` button, `Alt+R`) with **parameter locking** so locked
  knobs survive randomization.
- **Undo / Redo** (`Ctrl+Z`, `Ctrl+Shift+Z`, `Ctrl+Y`) via a JUCE `UndoManager`
  wired to the parameter tree, including preset/randomize/A-B gestures.
- **Dark / light theme toggle** (`Ctrl+T`) with a visible THEME button and a
  persisted user preference; look-and-feel, editor surface, effect panels, and
  the animated background all follow the active theme.
- **Output Trim** for final gain staging after the limiter.
- **Master Mid Drive / Side Drive / Width** mid-side controls and **Master
  Drive** push-pull saturation.
- **Stereo level meters** with peak/RMS display, decay, and dB scale markings.
- **Click-free bypass buttons** for all 5 modules.
- **Tooltips** on every parameter and the preset selector.
- **Keyboard and control reference** documented in the README.
- **CMake build infrastructure:** `windows-vs2026-release` configure/build
  presets, optional PGO configuration (`CORVUS_ENABLE_PGO`), compile-commands
  export, `CorvusDSPTestsRun` helper target, and the `CorvusFXStateTests`
  console target.

### Engineering / test infrastructure

- **Shared DSP core** extracted to `source/DrippyFX/dsp/CorvusEffects.h`, used
  by both FX and Instrument.
- **Deterministic DSP regression harness** (`CorvusDSPTests`) locking a
  deterministic effects fingerprint plus oscillator and voice/engine
  lifecycles.
- **FX session regression harness** (`CorvusFXStateTests`) covering A/B slots,
  MIDI maps, parameter locks, legacy/partial state, schema rejection, and
  dry/bypass paths.
- **Portable source gate** (`scripts/verify_corvus_source.sh`) running every
  `scripts/check_*.py` headless checker, including negative probes.
- **State schema version** written into saved processor state.

## Changed

### DSP

- **2x oversampling on all four non-linear stages** (Distortion, Chorus
  feedback, Delay tape saturation, Master push-pull saturation), using an
  **8-tap 2nd-order half-band FIR** with **SSE-optimized** polyphase
  up/down-sampling; per-channel and mono variants used where appropriate.
- **Zero per-sample transcendental calls** in the hot path: LFOs use
  phase-recurrence rotation with 256-sample magnitude renormalization, and
  `std::tanh` is replaced by Padé rational approximants (incl. `padeSoftClip`
  for the safety limiter).
- **Hermite cubic interpolation** for all modulated delay reads (Chorus, Delay,
  Reverb).
- **Block-level coefficient caching** across all modules — expensive math
  (`std::exp`, `std::pow`, `std::sin`) hoisted out of per-sample loops, with
  sample-rate-only constants moved into `prepare()`.
- **Parameter smoothing:** 20 ms `LinearSmoothedValue` on all continuous
  parameters; **30 ms** wet/dry ramps for click-free bypass on all 5 modules.
- **Reverb:** equal-power wet/dry crossfade, allpass diffusion feedback scaling
  with room size. Allpass diffusion modulation is now derived from the same
  master LFO as the comb filters, and early-reflection tap buffers are re-muted
  only when room size actually changes.
- **Delay:** exponential feedback mapping, tape wow/flutter LFO rate fix, and
  correct millisecond-to-samples conversion (`sr * 0.001f`).
- **Chorus:** LFO drift delta scaled by `twoPi`, sample-rate LFO conversions
  gated, and a redundant per-sample `std::sqrt` hoisted out of the hot path.
- **Master output:** push-pull asymmetrical saturation generating even
  harmonics, mid/side DC blockers, Padé [3/2] safety limiter, and Output Trim.
- **Oversampler:** separate up/down FIR histories so down-sample tails never
  feed the next up-sample; SSE lanes paired with the correct coefficient order;
  portable on Apple Silicon without the `xmmintrin` shim.

## Fixed

- **Delay ms-to-samples conversion bug** — presets previously produced ~0.02 ms
  delay regardless of the knob setting.
- **Host program-interface interop** — all 36 presets reachable via the DAW
  program interface; `getCurrentProgram`/`setCurrentProgram` combo-ID mapping
  fixed; preset combo range widened; `idToPreset` slot-0 desync fixed.
- **Master parameter smoothing** — added the missing `setTargetValue` calls for
  `master_drive`, `master_width`, and `master_mid_drive` so those knobs respond
  after load; fixed the `reverb_mod` smoothing regression.
- **MIDI Learn** — guarded arm writes and map reads under the MIDI map lock,
  returned a lock-guarded snapshot from `getMidiMappings`, snapshotted the map
  outside the lock before applying CC mappings, refused a CC already mapped to
  another parameter, no longer swallowed other CCs in the same block, stopped
  learning on editor close, and dropped restored maps whose parameter no longer
  exists.
- **State save/load** — guarded the save-side XML null dereference, cleared
  MIDI-learn maps before restore, stripped transport metadata from the
  parameter tree to prevent stale duplicates across repeated save/recall, and
  persisted A/B snapshots with plugin state.
- **Non-finite output safety** — non-finite samples are replaced with silence.
- **Reverb** — allpass diffusion modulation derived from the master LFO (was
  static); early-reflection buffers no longer re-muted on unrelated edits.
- **Oversampler** — split FIR history fixes (down-sample tails no longer
  contaminate the next up-sample); corrected SSE lane/coefficient pairing.
- **UI** — context menu offers *Cancel MIDI Learn* while armed; locked
  parameters show greyed text boxes and reflect restored locks; preset row
  width allocated for all control buttons; effect-grid dimensions clamped in
  responsive layout; unsupported level-meter tooltip call removed.
- **Cleanup** — removed dead per-sample parameters and dead block state from
  Chorus, Delay, Distortion, and the processor.
